# Roadmap

## Phase 1: Foundation & Walking Skeleton
**Goal**: Build the UI shell, integrate React Flow, and fetch basic 1-hop data from Mempool.space to prove the visualization works.
**Status**: Executing

## Phase 2: Common-Input Clustering Core
**Goal**: Implement the core clustering algorithm to group Bitcoin UTXOs by entity based on common inputs.
**Status**: Pending

## Phase 3: VASP Attribution Engine
**Goal**: Build the matching engine (using JSON VASP database) and find the shortest paths from entity clusters to known VASPs.
**Status**: Pending

## Phase 4: Polish & Reporting (PostgreSQL transition)
**Goal**: Enhance the UI, generate printable reports, and migrate the VASP database to PostgreSQL for production deployment.
**Status**: Pending
